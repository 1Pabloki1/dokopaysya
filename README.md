# Докопайся (dokopaysya)

Скилл для Claude Code: **структурированный допрос идеи перед любой работой — и в итоге готовое ТЗ**.

Говоришь «хочу CRM для языковой школы», «запускаю маркетинговую кампанию» или «хочу собрать курс». Агент не бросается делать. Он допрашивает тебя раундами по 3–5 вопросов, докапывается до сути, ловит противоречия, режет лишнее из первой версии. Когда всё ясно — пишет **ТЗ в Markdown**: сценарии, данные, интеграции, план по этапам и готовый промпт, чтобы сразу начать делать.

**Работает для любых идей:** софт (агенты, боты, CRM, ERP, платформы, сайты, автоматизации) и не только: стартапы, маркетинговые кампании, курсы, контент-планы, найм, события, бизнес-процессы.

Отвечает на русском и украинском — на том языке, на котором пишешь ты.

---

## Установка

### Способ 1. Плагин (рекомендуется, обновляется сам)

В Claude Code по очереди введи две команды:

```
/plugin marketplace add 1Pabloki1/dokopaysya
```

```
/plugin install dokopaysya@dokopaysya
```

Перезапусти Claude Code.

### Способ 2. Попроси Claude установить

Вставь в Claude Code одним сообщением:

> Установи скилл из https://github.com/1Pabloki1/dokopaysya: скопируй папку `skills/dokopaysya` в `~/.claude/skills/dokopaysya`. Потом проверь, что в ней есть файлы `SKILL.md` и `TZ-TEMPLATE.md`.

### Способ 3. Вручную (macOS / Linux)

```bash
git clone https://github.com/1Pabloki1/dokopaysya.git /tmp/dokopaysya && mkdir -p ~/.claude/skills && cp -R /tmp/dokopaysya/skills/dokopaysya ~/.claude/skills/
```

## Как пользоваться

Открой Claude Code в папке, где будешь делать проект, и напиши:

```
/dokopaysya хочу CRM для языковой школы
```

Или просто «докопайся, хочу сделать бота для записи клиентов» — скилл подхватится сам.

**Что будет дальше:**

1. **Раунды вопросов.** 4–10 раундов по 3–5 вопросов. К каждому вопросу есть рекомендация агента.
2. **Контрольная точка.** Агент пересказывает, как он всё понял, и показывает, что решил за тебя. Ты подтверждаешь или поправляешь.
3. **ТЗ.** Файл `docs/TZ-<название>.md` (или `TZ-<название>.md`, если проекта ещё нет).
4. **Что дальше.** Начать этап 1 сразу, открыть новую сессию с готовым промптом или отдать ТЗ исполнителю.

**Как отвечать быстро:**

| Пишешь | Что это значит |
|---|---|
| `согласен` | Принимаю все рекомендации раунда |
| `1а, 2 согласен, 3 — иначе: …` | Ответ по пунктам |
| `не знаю` | Агент предложит вариант и пометит его как допущение |
| `на твоё усмотрение` | Агент решит сам и запишет, что решил |
| `хватит, пиши ТЗ` | Перейти к документу в любой момент |

**Займёт 15–30 минут.** Это лучшее вложение получаса проекта: оно экономит дни переделок.

## Что в ТЗ

Суть и проблема · Пользователи и роли · Сценарии с критериями «готово» · Функции первой версии и что откладываем · Данные и сущности · Интеграции · AI-часть с примерами диалогов · Интерфейс · Доступы и безопасность · Технические решения · Метрики и запуск · План по этапам · Риски · Открытые вопросы · Готовый промпт для старта реализации

Решения агента и допущения отмечены отдельно, чтобы ты видел, что он решил сам, а что — за тебя.

Повторный запуск `/dokopaysya` в проекте, где уже есть ТЗ, дорабатывает его и сохраняет новую версию (`-v2`, `-v3`), старые не перезаписываются.
