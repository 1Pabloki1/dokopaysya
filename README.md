# Brainstorm

Скилл для Claude Code, который **сначала прожаривает твою идею, а потом пишет ТЗ**.

Ты говоришь: «хочу CRM для языковой школы» или «хочу AI-агента, который отвечает клиентам в Instagram». Агент не бросается писать код. Он допрашивает тебя раундами по 3–5 вопросов, докапывается до сути, ловит противоречия и режет лишнее из первой версии. Когда всё понятно, он пишет **ТЗ в Markdown**: сценарии, данные, интеграции, план по этапам и готовый промпт, чтобы сразу начать реализацию.

Работает на русском и украинском: агент отвечает на том языке, на котором пишешь ты.

---

## Установка

### Способ 1. Плагин (рекомендуется, обновляется сам)

В Claude Code по очереди введи две команды:

```
/plugin marketplace add 1Pabloki1/brainstorm
```

```
/plugin install brainstorm@brainstorm
```

Перезапусти Claude Code.

### Способ 2. Попроси Claude установить

Вставь в Claude Code одним сообщением:

> Установи скилл из https://github.com/1Pabloki1/brainstorm: скопируй папку `skills/brainstorm` в `~/.claude/skills/brainstorm`. Потом проверь, что в ней есть файлы `SKILL.md` и `TZ-TEMPLATE.md`.

### Способ 3. Вручную (macOS / Linux)

```bash
git clone https://github.com/1Pabloki1/brainstorm.git /tmp/brainstorm && mkdir -p ~/.claude/skills && cp -R /tmp/brainstorm/skills/brainstorm ~/.claude/skills/
```

## Как пользоваться

Открой Claude Code в папке, где будешь создавать проект, и напиши:

```
/brainstorm хочу CRM для языковой школы
```

Или просто «прожарь меня, хочу сделать бота для записи клиентов» — скилл подхватится сам.

**Что будет дальше:**

1. **Раунды вопросов.** 4–10 раундов по 3–5 вопросов. К каждому вопросу есть рекомендация агента.
2. **Контрольная точка.** Агент пересказывает, как он всё понял, и показывает, что решил за тебя. Ты подтверждаешь или поправляешь.
3. **ТЗ.** Файл `docs/TZ-<название>.md` (или `TZ-<название>.md`, если проекта ещё нет).
4. **Что дальше.** Начать этап 1 сразу, открыть новую сессию с готовым промптом или отдать ТЗ разработчику.

**Как отвечать быстро:**

| Пишешь | Что это значит |
|---|---|
| `согласен` | Принимаю все рекомендации раунда |
| `1а, 2 согласен, 3 — иначе: …` | Ответ по пунктам |
| `не знаю` | Агент предложит вариант и пометит его как предположение |
| `на твоё усмотрение` | Агент решит сам и запишет, что решил |
| `хватит, пиши ТЗ` | Перейти к документу в любой момент |

**Займёт 15–30 минут.** Это лучшее вложение получаса проекта: оно экономит дни переделок.

## Что в ТЗ

Суть и проблема · Пользователи и роли · Сценарии с критериями «готово» · Функции первой версии и что откладываем · Данные и сущности · Интеграции · AI-часть с примерами диалогов · Интерфейс · Доступы и безопасность · Технические решения · Метрики и запуск · План по этапам · Риски · Открытые вопросы · Готовый промпт для старта реализации

Решения агента и предположения отмечены отдельно, чтобы ты видел, что он решил сам, а что — за тебя.

Повторный запуск `/brainstorm` в проекте, где уже есть ТЗ, дорабатывает его и сохраняет новую версию (`-v2`, `-v3`), старые не перезаписываются.
